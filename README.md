Desenvolvemos um projeto utilizando HTML
e CSS para uma empresa de pastilhas, com 
foco principal na criação de uma interface
moderna, intuitiva e altamente interativa. 
Durante o desenvolvimento, priorizamos a
usabilidade e a visibilidade dos elementos, 
garantindo que o usuário tenha uma navegação 
clara e eficiente. O design foi cuidadosamente 
planejado para proporcionar uma experiência
agradável, destacando informações importantes
e facilitando a interação com o conteúdo.

Os botões foram projetados com tamanho ampliado 
e cores chamativas, com o objetivo de facilitar 
a visualização e a interação do usuário. Buscamos
transmitir uma interface profissional, sem abrir
mão da intuitividade, permitindo que qualquer
pessoa consiga utilizar o sistema com facilidade.
Além disso, o design foi pensado para comunicar 
claramente a presença de diversas funcionalidades,
tornando a navegação mais dinâmica e eficiente.
